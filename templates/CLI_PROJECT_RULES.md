# CLI_PROJECT_RULES.md — 项目级执行规范模板

> 使用方式：将本文件复制到你的代码仓库根目录，重命名为 `CODEBUDDY.md`（或 `AGENTS.md`），并按需补充项目专属红线。

## 1. 适用范围
- 独立脚本、单测编写、文档生成、日志初筛、1～2 个文件内的明确功能修改与样式调整。

## 2. 项目业务红线（按需填写）
- 示例：严禁修改核心计费/鉴权模块，除非派单明确授权。
- 示例：保持既有对外 API 字段与事件名向后兼容。

## 3. 禁止操作
- 严禁修改、清空或覆盖运行时缓存、数据库文件或 `.env` 密钥配置。
- 严禁删除目录、执行 `git push` 或 `git reset --hard`。
- 严禁修改未在派单白名单中的文件。

## 4. 交付要求
- 改动后必须运行对应的语法检查或单元测试（如 `pytest` / `npm test` / `node --check`），并汇报改动文件清单与验证结果。
